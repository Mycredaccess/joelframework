IMPORTANT: EMAIL DELIVERY SETUP REQUIRED
The website cannot email attachments until EmailJS is configured. Open EMAIL-SETUP.txt and replace the three placeholder values in order-config.js:
- emailJsServiceId
- emailJsTemplateId
- emailJsPublicKey

Do not add a private API key or Gmail password to website files.
The configured owner email is designsabhinav@gmail.com. The WhatsApp notification number is set in order-config.js.
When EmailJS is not configured or sending fails, the site downloads the original image(s) and previews as a manual fallback and opens WhatsApp with an order notification. A wa.me link cannot silently attach image files; the owner must receive images through the configured email attachment workflow or the customer must attach them manually in WhatsApp.
